## 1. A1和交付边界

A1通常是专利申请公开文本的文献种类代码，不是专利质量等级，也不代表授权。本项目交付可运行实施例、技术交底、权利要求建议稿、说明书、摘要、附图、现有技术初筛和源码证据矩阵，但不能保证公开、授权、稳定保护范围或自由实施。

正式提交前必须由代理师确认申请主体、发明人、权属、最早公开、优先权、保密审查、法定期限、费用、同族和正式检索结论。

## 2. 首选题名

> **一种基于来源约束影响域和因果验证凭证的知识图谱候选图补丁验证和版本提交方法、系统、设备及介质**

标题不再突出“Agent”“联合抽取”或“自进化”，因为这些词拥挤且偏产品宣传。真正保护对象是自动KG写入的计算机数据完整性控制链。

## 3. 发明中心

```text
固定父版本基线 + 来源绑定候选图补丁
        ↓
由来源锚、声明影响对象、端点依赖和基线邻接
派生并冻结原始影响域摘要
        ↓
影子结构查询与冻结域外投影
        ↓
逐关联操作执行依赖闭包排除和同基线反事实重放
        ↓
在反事实候选空间确定待排除集合并重验剩余子补丁
        ↓
生成并两阶段重算内容寻址因果验证凭证
        ↓
三方接受操作一致 + 提交清单幂等核对
        ↓
事务写入实际接受操作、图事件、图版本和凭证关联；否则隔离
```

主权项每一步必须消费上一步的机器输出。不能只列“Agent、影子图、门控、版本”等功能模块。

## 4. 创新点分层

### 4.1 核心A层

1. **冻结来源约束影响域**：局部排除操作后仍使用完整候选补丁派生的原始边界，防止验证范围随repair缩小。
2. **依赖闭包反事实原因验证**：静态关联操作只有在同基线排除重放后目标失败消失，才成为原因候选。
3. **内容寻址因果验证凭证**：绑定基线、候选操作、冻结域、查询原因、求解器、排除/接受操作、最终影子和门结果。
4. **凭证绑定的实际提交选择**：decision、evaluation和certificate三方接受操作相等；commit再次重算。
5. **提交清单幂等语义**：patch、parent、接受操作摘要和certificate ID共同持久化；同patch不同selection拒绝。

### 4.2 回退B层

- 依赖闭合局部排除和剩余子补丁重验；
- 同批次提及端点及证据先行关系引用校验；
- same-type、来源完整、跨簇任意成员对实体合并；
- 限定信息关系身份和逐条源断言快照；
- contribution、tombstone、新生命周期及安全跳过的历史补偿。

### 4.3 非核心C层

- noisy-OR及关系置信度上限；
- Agent EIG-cost-risk调度公式；
- 普通发布评分；
- schema proposal晋升；
- 控制台可视化；
- 模型、框架、数据库和编程语言品牌。

C层保留在说明书、商业秘密、软件著作权或分案储备中，不占用主权项创造性预算。

## 6. 保护写法

### 6.1 保护数据结构，不保护名称

竞争者可把EvidenceContract改名为provenance envelope，把certificate改名为validation manifest。权利要求应写字段及其被下游消费的关系：

- 来源文档/片段/提及/证据/源候选锚；
- 声明影响实体、关系和谓词；
- 关系端点依赖；
- 查询标识、关联操作、反事实闭包及目标失败状态；
- 排除/接受操作、求解模式、最终影子和门结果；
- 父版本、接受操作摘要、凭证ID及提交清单摘要。

### 6.2 保护等价实现

| 当前实现 | 权项抽象 |
|---|---|
| SHA-256 + canonical JSON | 确定性规范序列化及内容摘要；SHA-256作为实施例 |
| Python内存影子图 | 固定于父版本的隔离执行环境 |
| SQLite `BEGIN IMMEDIATE` | 具有等效原子提交和父版本排他校验的事务存储 |
| 枚举≤16 | 小候选空间精确求解；阈值作为从属限定 |
| 固定点单删除回退 | 带明确局部/非全局性质标记的确定性回退 |
| Agent模块 | 技术判定模块或处理模块 |
| complete-link | 两拟合并簇的任意跨簇成员对均满足等价条件 |

### 6.3 明确不主张

- 凭证是数字签名或知识真实性证明；
- 任意业务查询语义等价；
- 任意规模全局最小repair；
- arbitrary/commutative rollback；
- 所有历史贡献均可无条件移除；
- 跨候选库、schema库、运行库和规范图的分布式原子事务；
- 在线修改模型权重；
- 当前自有语料证明开放域SOTA。

诚实边界可减少支持性和不充分公开攻击。

## 7. 现有技术抗辩主线

详细矩阵见[prior_art_matrix.md](../patent/prior_art_matrix.md)。最强组合为：

1. CN120179832A + CN121787546A + US7873605B2；
2. US20260004204A1 + US12135740B1 + 查询因果/database repair + delta debugging；
3. MentionId关系端点 + 实体/关系canonicalization + KG change layer。

抗辩不能说“组合文献没有Agent”或“本案用于KG”。应说明相互制约的技术关系：

- 若不冻结原始域，排除操作后验证边界可以收缩；
- 若不做反事实重放，查询静态关联会扩大或错误定位repair候选；
- 若凭证不绑定接受操作，decision篡改可让未验证集合进入commit；
- 若幂等键只包含完整patch，重试时不同接受集合可错误命中旧版本；
- 四个问题由同一数据链连续解决，不是并列功能汇总。

## 8. 商业价值

### 8.1 客户痛点

- LLM/规则抽取结果不能直接进入生产KG；
- 一条坏关系导致整批数据人工回滚；
- 无法解释某个版本为何通过、排除了什么；
- 数据血缘、审计、幂等和并发控制分散在多套系统；
- 模型供应商可替换，但治理控制面需要长期稳定。

### 8.2 产品形态

1. **KG Change Control Gateway**：位于抽取器和图数据库之间，验证所有候选patch。
2. **Managed Governance Service**：托管影子执行、凭证、审批和版本事件。
3. **Enterprise Connector SDK**：接入Neo4j、RDF store、数据目录、RAG知识库或主数据平台。
4. **Compliance Evidence Pack**：按图版本导出来源、查询原因、排除集合、凭证和提交清单。
5. **Domain Edition**：科研、制造、运维、医药法规或专利情报等高审计行业版本。

### 8.3 可量化价值指标

- 错误patch阻断率；
- 有效操作保留率；
- 全图验证相对冻结影响域验证的读取/延迟降低；
- 人工定位时间降低；
- stale/tampered decision检出率；
- 同patch冲突重试拒绝率；
- 可追溯关系覆盖率；
- 单文档模型调用和推理成本。

## 9. 组合式知识产权布局

### 主案

来源约束影响域、反事实局部排除、因果验证凭证及提交清单绑定的KG候选补丁控制面。

### 分案候选A

联合提及端点、证据先行引用校验、同类型跨簇实体合并、限定关系身份和源断言快照。

### 分案候选B

版本贡献、删除墓碑、新生命周期、安全跳过和追加式历史补偿。

### 其他权利

- 源代码和文档：著作权；
- 提示模板、阈值、别名词典、客户规则和性能参数：商业秘密；
- EvoLex及产品名称：商标评估；
- UI和图形资产：视情况进行著作权或外观设计评估；
- 公开论文：注意申请前公开与专利新颖性时间协调。

## 10. 正式申请前证据计划

1. 冻结代码提交、测试报告和生成文档的hash；
2. 记录每位发明人对冻结域、反事实、凭证、提交清单、联合抽取和历史补偿的实质贡献；
3. 确认最早Git公开、论文、演示、客户交付和邮件披露日期；
4. 对新权1逐限制完成中美欧PCT和论文claim chart；
5. 运行公开数据集消融和控制面故障注入实验；
6. 保存基线、篡改输入、失败结果和通过结果，形成可复现实验包；
7. 代理师确认权12是否分案以及是否增加计算机程序产品类别；
8. 依据申请时规则处理保密审查、优先权、提前公开和实审请求。
