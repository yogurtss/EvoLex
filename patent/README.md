## 当前保护中心

本案不把“Agent 抽取知识图谱”作为孤立创新，而保护以下连续数据依赖链：

```text
固定父版本基线与来源绑定候选图补丁
→ 派生并冻结原始影响域
→ 影子结构查询和冻结域外投影
→ 依赖闭包排除的同基线反事实原因验证
→ 待排除集合与剩余子补丁重验
→ 内容寻址因果验证凭证及 Evidence/replay/non-interference/invariant/utility/certificate 六项 AND 硬门
→ 判定与提交阶段两次重算凭证并核对三方接受操作一致
→ 提交清单绑定实际接受操作、凭证和图版本
→ 剩余操作版本事务或隔离
```

反事实原因候选不超过16个时仅在已定义搜索空间内精确枚举；超过16个时使用确定性固定点单删除回退，只保证单删除局部最小，并明确不保证全局最优或一般集合包含极小。`required_quorum=5`仅作为审计统计，不能覆盖六项硬条件中的任一失败。

自动演化主链限定为来源完整的 `upsert` 补丁。普通 `delete` 不由当前自动 planner/影子链处理；已提交对象的删除、墓碑和历史版本补偿作为单独的版本存储从属特征。联合抽取和实体/关系规范化属于上游从属保护层，不是主创新中心。

## 可复现构建

在项目根目录执行：

```bash
python patent/build_package.py
```

该脚本依次重建阶段工件、执行结构/溯源校验、调用专利技能生成标准包、使用项目内字体子集重建中文图件，并重新渲染包含附图的四个 DOCX。若技能不在默认目录，可传入 `--skill-dir`。项目已随附仅包含本案图件字符的 Noto CJK 字体子集。
