# EvoLex 中国发明专利严格审查与第二轮重构报告

审查日期：2026-07-31  
审查对象：第一轮16项权利要求、说明书、附图、证据台账及对应源码  
审查立场：同时模拟实质审查员、无效请求人和规避设计者  

> 本报告是技术性专利草拟与申请前风险分析，不是法律意见、可专利性保证、自由实施意见或授权承诺。A1是专利文献种类代码，不是质量等级。

## 一、结论先行

第一轮草稿有真实商业问题和可实施系统，但不宜按原权利要求1—16直接申请。旧主权项把“联合抽取与双层规范化”和“候选补丁验证与局部排除”两个技术问题串成长达S1—S8的聚合链，容易被多个已知模块组合攻击，也使只接收外部补丁的竞争实现整体规避。

第二轮把发明中心收敛为：

> **来源绑定候选图补丁 → 冻结原始影响域 → 同基线反事实原因验证 → 依赖闭合局部排除 → 内容寻址因果验证凭证 → 提交清单绑定的剩余子补丁版本提交。**

联合抽取、证据先行校验、同类实体合并、限定关系身份和历史版本补偿保留为从属保护层；noisy-OR、Agent动作效用、普通发布评分、schema晋升和控制台展示不再承担核心创造性。

## 四、最强现有技术组合攻击

### 攻击A：知识图谱增量更新链

- [CN120179832A](https://patents.google.com/patent/CN120179832A/en)：联合实体关系抽取、对齐、差异、create/modify/delete、sandbox模拟、事务组、版本快照和回滚。
- [CN121787546A](https://patents.google.com/patent/CN121787546A/en)：实体关系增量单元、ID引用校验、影响域、局部子图、去重合并和证据融合。
- [US7873605B2](https://patents.google.com/patent/US7873605B2/en)：依赖事务因果集合和选择性补偿事务。

组合动机很直接：为避免增量KG污染正式图，先在局部环境模拟，再按依赖选择性排除失败相关操作。因此“联合抽取+影响域+sandbox+依赖补偿+版本”不是稳固区别。

### 攻击B：影子验证、查询因果和数据库修复

- [US20260004204A1](https://patents.google.com/patent/US20260004204A1/en)：原始ontology map与test map、两次执行输出、loss/cost阈值及通过后推广。
- [US12135740B1](https://patents.google.com/patent/US12135740B1/en)：同一查询跨图版本执行、比较并按差异节点/边回退。
- [Meliou等，PVLDB](https://www.vldb.org/pvldb/vol4/p34-meliou.pdf)：query lineage、actual cause、最小contingency与responsibility。
- [Salimi与Bertossi，ICDT 2015](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ICDT.2015.342)：查询原因、数据库repair、诊断及hitting set/vertex cover的联系。
- [Data-graph set repairs，2022](https://arxiv.org/abs/2206.07504)与[Property graph constraint repair，2026](https://arxiv.org/abs/2602.05503)：图约束下的subset/superset repair及ILP/greedy删除策略。

这一组合几乎完整给出“测试图失败→约束结果→原因/lineage→最小删除→重放”。第二轮只能依靠KG操作特定来源边界、端点依赖反事实闭包、内容寻址凭证和未提交剩余子补丁清单绑定的连续耦合抗辩。

### 攻击C：联合抽取与双层规范化

- [US20120197862A1](https://patents.google.com/patent/US20120197862A1/en)：关系端点使用MentionId。
- [REBEL](https://aclanthology.org/2021.findings-emnlp.204/)与[TDEER](https://aclanthology.org/2021.emnlp-main.635/)：联合实体关系抽取。
- [US20230087667A1](https://patents.google.com/patent/US20230087667A1/en)：实体和关系canonicalization，并明确complete linkage。

因此，联合抽取和complete-link可支撑产品质量与从属保护，但不能独自承担主创新。

## 六、第二轮实现补强及其专利意义

| 实现补强 | 技术故障 | 证据 |

| 维度 | 修订后自评 | 尚需完成 |

| 技术效果推理 | 4/5 | 补全图验证读取量、知识保留率、原因精度和凭证检出率实验 |
| 公式覆盖 | 5/5 | 数学式排版及代理师确认 |
| 附图对齐 | 5/5 | 代理师确认是否需要删减图5、图6或用于分案 |

最高剩余风险不是代码支持，而是创造性：数据库因果与repair邻域非常接近。正式申请前应针对新权1逐限制检索中国、PCT、美国和论文，重点寻找“来源边界冻结+反事实操作闭包+内容寻址验证清单+只提交未提交剩余图操作”的组合公开。

必须由发明人确认：最早公开日期、发明人贡献、申请人权属、是否向境外披露、是否需要保密审查，以及是否把历史版本补偿方案作为分案。
