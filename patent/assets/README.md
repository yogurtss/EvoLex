# Patent figure font asset

`EvoLexPatentCJK-Subset.otf` is a character subset generated from
`NotoSansCJKsc-Regular.otf` in the official
[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) repository.

It contains only glyphs required by the EvoLex patent figures. The subset is
used by `patent/render_figures.py` for readable Chinese PNG output and is
embedded into the portable SVG files. It remains distributed under the SIL
Open Font License 1.1 in `LICENSE-Noto-CJK.txt`.
